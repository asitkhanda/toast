## Toast 0.5.0: Cloudflare support and a redesigned Toast

Toast now works with **Cloudflare**, and the whole app has been redesigned to be easier to set up, easier to read and easier to use.

### New: Cloudflare Pages and Workers
- Watch your Cloudflare **Pages** sites and **Workers** next to your Vercel projects.
- Pages show each build stage. Workers connected to Git show real build status: queued, building, failed or live.
- Use a read-only Cloudflare token. Toast walks you through the exact permissions to choose:
  - Account Settings: Read
  - Cloudflare Pages: Read (for Pages)
  - Workers Scripts: Read (for Workers)
  - Workers Builds Configuration: Read (optional, for live Workers build progress)
- If you watch both services, switch between them with the new tabs at the top.

### A redesigned Toast
- **A new look for macOS 26.** Glass buttons, flat rows and a cleaner layout that feels at home on your Mac.
- **A clear summary.** The top of the menu now says things like "All 8 projects are live" or "1 failed, 2 live".
- **Guided setup.** A five-step welcome explains what Toast does, shows how to create your token, and lets you search and select projects.
- **Settings in tabs.** General, Accounts, Projects, Notifications, Privacy and About, with a one-click connection test.
- **Plain-language errors.** Every problem says what happened and what to do next, with a button to fix it.
- **Friendlier notifications.** "my-site is live" or "my-site failed to deploy".

### Easier for everyone to use
- Every status has an icon and a word, not just a color.
- Larger text and stronger contrast. Increase Contrast and Reduce Motion are respected.
- VoiceOver reads a full summary for the menu bar icon and for each project.
- Keyboard shortcuts: ⌘R refresh, ⌘, settings, ⌘Q quit.

### Website
The [website](https://toast.asit.space) is redesigned with dark mode, a live preview of the app, clearer install steps and a short FAQ. The privacy policy and terms now mention Cloudflare.

### Good to know
- Your existing Vercel setup carries over. You don't need to do anything.
- Cloudflare support is on macOS for now. The Windows app is unchanged in this release (version number only) and still supports Vercel.
- Installed with Homebrew? `brew upgrade --cask toast-app`. Otherwise Toast updates itself through Sparkle.
