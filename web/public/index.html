Set up in about two minutes

Toast walks you through each step, including exactly which token permissions to choose.

  1. Install Toast

    On a Mac, open the downloaded file and drag Toast into Applications, then open it. On Windows, run the Setup file. Toast appears in your menu bar or system tray.

  2. Connect your service

    Pick Vercel or Cloudflare and paste a token. Toast only reads deployment status. It can't change or delete anything.

  3. Choose your projects

    Tick the projects to watch, then decide whether to get notifications and start Toast at login. That's it.

Your token stays on your computer. Toast keeps it in the macOS Keychain or Windows Credential Manager, and only sends it to Vercel or Cloudflare to read your status.

What the icon is telling you

Every status has its own shape and a word, so you never have to rely on color alone.

  • Live

    The latest deployment finished and is serving visitors.

  • Building

    A deployment is queued or running. Toast checks every 5 seconds.

  • Failed

    The build failed or was canceled. Open Toast to see which project.

  • Not connected

    Toast can't reach your account. Open Settings to reconnect.

Works with where you deploy

Vercel

Watch any project on your teams. See the status, branch and commit of the latest deployment, and jump straight to it.

  • Create a token scoped to just the team you want to watch.
  • Available on macOS and Windows.

Cloudflare Pages and Workers

Pages projects show each build stage. Workers connected to Git show real build progress, and the rest show their latest deployment.

  • Create a custom token with Account Settings, Cloudflare Pages and Workers Scripts set to Read.
  • Optional: Workers Builds Configuration (Read) for live build progress.
  • Available on macOS. Windows is next.

Questions

Is it safe to give Toast a token?

Toast only reads deployment status, and your token never leaves your computer except to go to Vercel or Cloudflare. For extra safety, give the token the fewest permissions possible: one team on Vercel, and only Read permissions on Cloudflare. You can revoke it at any time from your account.

Read the privacy policy for details about the optional anonymous analytics.

Which Cloudflare permissions do I need?

Create a custom token and add these, each set to Read:

  • Account → Account Settings
  • Account → Cloudflare Pages (to watch Pages projects)
  • Account → Workers Scripts (to watch Workers)
  • Account → Workers Builds Configuration (optional, for live Workers build progress)
Does Toast work on Windows?

Yes, with Vercel. Cloudflare support is on macOS first and is coming to Windows.

macOS says it can't open Toast. What do I do?

Current downloads are signed and checked by Apple, so this shouldn't happen. If it does with an older download, right-click Toast, choose Open, then Open again, once.

How do I uninstall Toast?

In Toast, open Settings → Accounts and choose Disconnect to remove your tokens. Then choose More → Quit Toast and drag Toast from Applications to the Trash.

Installed with Homebrew? Run brew uninstall --cask toast-app.
