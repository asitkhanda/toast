Questions.

Is it safe to give Toast a token?

Toast only reads deployment status. Your token stays in your Mac's Keychain (or Windows Credential Manager) and is only sent to Vercel or Cloudflare. Give it the fewest permissions possible: one team on Vercel, and only Read permissions on Cloudflare. You can revoke it any time from your account.

Read the privacy policy for the details.

Which Cloudflare permissions do I need?

Create a custom token with these, each set to Read: Account Settings, Cloudflare Pages (for Pages), Workers Scripts (for Workers), and optionally Workers Builds Configuration for live Workers build progress. Toast lists them during setup.

Does Toast work on Windows?

Yes, with Vercel. Cloudflare support is on macOS first and is coming to Windows.

macOS says it can't open Toast.

Current downloads are signed and checked by Apple, so this shouldn't happen. With an older download, right-click Toast, choose Open, then Open again, once.

How do I uninstall Toast?

In Settings, open Accounts and choose Disconnect to remove your tokens. Then choose More, Quit Toast, and drag Toast from Applications to the Trash. Installed with Homebrew? Run brew uninstall --cask toast-app.
